# FastAF Agent Skills

Agent Skills for [FastAF](https://fastaf.co): web scraping, Google SERP and Amazon prices for AI agents. Pay per call via x402 or use the MCP server.

```bash
npx skills add fastaf-co/fastaf-skills
```

Skills:
- `fastaf-web-data`: scrape URLs to markdown, Google SERP, Amazon product data.

More: https://fastaf.co · MCP: https://api.fastaf.co/mcp · OpenAPI: https://api.fastaf.co/openapi.json
