# FastAF Agent Skills

Agent Skills for [FastAF](https://fastaf.co): live web data using MCP, API keys
or explicitly authorized x402 payments.

```bash
npx skills add fastaf-co/fastaf-skills
```

- `fastaf-web-data`: 22 verified MCP tools; web/image search, Reddit without
  authors, LinkedIn jobs, patents, flights, YouTube, scraping and products.
- Proposed skill metadata version: **0.2.0**, not merged/published.
- This is a GitHub-distributed skill, not a new npm/PyPI package.
  After approval, merging the PR updates what the install command retrieves.

Tests: `node --test test/*.test.mjs`.
